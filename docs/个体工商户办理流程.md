# 个体工商户办理流程

> 用途：为了申请微信支付商户号（需要营业执照主体），先把个体工商户营业执照办下来。
> 适用对象：个人开发者 / 自由职业者。
> 大致成本：0–500 元（自办免费；找代办 200–500 元）。
> 大致周期：线上 1–3 个工作日下电子执照；线下窗口当天或 1 周内。

---

## 一、办之前要先想清楚的 5 件事

| 决策项 | 说明 | 给"做小程序+微信支付"的建议 |
|---|---|---|
| **注册地址** | 个体户必须有经营地址。可以是自家住宅（多数城市允许"住改商"，需要居委会/物业证明）、租赁的商业地址、或挂靠到"集群注册"地址。 | 自家住宅最便宜；担心隐私就用集群注册（淘宝 100–300 元/年） |
| **字号名称** | 格式：`地区 + 字号 + 行业 + 组织形式`，例如"杭州市西湖区 **某某** 软件开发工作室"。需要先做名称预查。 | 准备 3-5 个备选字号，避免重名 |
| **经营范围** | 决定你能做什么生意；后面微信支付审核会对照这个范围核类目。 | 必须包含：**软件开发、信息技术服务、技术咨询**。**不要写**"投资咨询、金融信息服务、证券咨询"——会触发金融牌照要求 |
| **行业组织形式** | 工作室 / 商行 / 中心 / 服务部 等。 | "**工作室**"或"**信息技术服务部**"最常见，不影响后续 |
| **是否核定征收** | 影响纳税方式。 | 个体户默认定额或核定征收，月营收 10 万以下基本不交增值税；先办下来再说，后面去税务报到时确认 |

---

## 二、需要准备的材料

- 身份证原件 + 正反面照片
- 本人手机号（要能接收验证码）
- 经营地址证明：
  - 自有房产：房产证扫描件
  - 租赁：租赁合同 + 房东身份证 + 房产证复印件
  - 集群注册：代办机构提供的地址使用证明
  - 自家住宅："住改商"证明（居委会盖章，部分城市免）
- 字号备选名（3-5 个）
- 经营范围草稿
- 银行卡（个人储蓄卡即可，后期开店铺、绑微信支付要用）

---

## 三、办理路径（选一种）

### 路径 A：全程网办（推荐，最快最便宜）

各省"政务服务网"或"市场监管局 APP"都有线上办理入口。以**浙江/广东/江苏/上海**为例最完善。

**通用步骤：**

1. **下载/登录当地政务 APP**
   - 浙江：浙里办
   - 广东：粤商通
   - 江苏：苏服办
   - 上海：随申办
   - 北京：北京通
   - 其他省：搜"<省/市>政务服务网"
2. **实名认证**：用身份证 + 人脸识别
3. **进入"开办企业"或"个体工商户设立登记"模块**
4. **填写字号名称** → 系统自动查重
5. **填写经营信息**：地址、范围、资金（个体户写 1 万即可，不用实缴）
6. **上传材料**：身份证、地址证明
7. **法人本人扫脸签名**
8. **提交审核** → 1-3 个工作日

**审核通过后：**
- 收到短信通知
- 电子营业执照在政务 APP 内查看/下载（PDF/图片）
- 想要纸质版可以预约到工商窗口领取，或邮寄

### 路径 B：线下窗口

去户籍地或经营地的**市场监督管理局 / 政务服务中心**，找"个体工商户登记"窗口。

- 现场领表填写，或现场用一体机办理
- 当天或 3-5 个工作日下证
- 适合不熟悉线上操作的人

### 路径 C：找代办（最省事）

淘宝/拼多多搜 "个体工商户注册 代办"，200–500 元包办。

**优点：** 不用自己填表、不用自己跑窗口，地址也可以打包（集群注册）
**缺点：** 后期挂靠地址要按年续费

## 四、拿到营业执照后必做的 4 件事

| # | 事项 | 怎么做 | 何时做 |
|---|---|---|---|
| 1 | **税务报到** | 电子税务局登录 → 完成"首次办税" → 确认征收方式（小规模/定期定额） | 拿到执照后 30 天内（逾期罚款） |
| 2 | **刻章**（可选） | 个体户不强制要公章。如果要刻：政务大厅旁有备案刻章点，公章+财务章 200 元左右 | 想刻随时 |
| 3 | **开对公账户**（可选） | 拿执照去银行开"个体工商户结算账户"，工本费 0-500 元/年。**微信支付可以用法人个人储蓄卡结算**，不开对公也行 | 申请微信支付前 |
| 4 | **申领发票**（按需） | 在电子税务局申请"票种核定" → 可以开电子普票 | 客户要发票时 |

## 五、申请微信支付商户号（拿到执照后）

> 这是办执照的最终目的，单独写在 [`微信支付商户号申请.md`](./微信支付商户号申请.md) 里。本文档先给关键节点：

1. 打开 https://pay.weixin.qq.com → "商家接入"
2. 主体类型选 **个体工商户**
3. 上传营业执照、法人身份证
4. 经营场景选 **小程序**，填写小程序 AppID `wx145f0e364826d176`
5. 行业类目选 **IT 服务/软件开发** 或 **商务服务-软件服务**（**不要选金融/证券**）
6. 结算账户填法人本人储蓄卡（个体户允许）
7. 法人扫脸签约
8. 1-5 个工作日审核 → 通过后拿到商户号 `MCH_ID`

## 六、常见坑

| 坑 | 后果 | 避坑 |
|---|---|---|
| 经营范围写"金融信息服务"/"投资咨询" | 微信支付审核要求增值电信业务许可证（ICP）+ 金融牌照，办不下来 | 经营范围只写"软件开发、信息技术服务、技术咨询、企业管理咨询" |
| 字号和别人重名 | 名称预查通不过，反复改 | 多准备几个生僻字号 |
| 用别人房产证但没拿到房东配合证明 | 地址核查驳回 | 选自家住宅或集群注册 |
| 拿到执照后不去税务报到 | 30 天后开始罚款 + 列入异常 | 立刻去电子税务局完成首次办税 |
| 长期 0 申报又没经营 | 一年以上可能被列入经营异常名录 | 哪怕没收入，每月也按时做 0 申报 |
| 经营范围里没有"软件开发"就去申请微信支付 | 微信支付审核驳回 | 办执照时就把经营范围写全 |

## 七、时间线参考（理想情况）

| 阶段 | 用时 |
|---|---|
| 准备材料 + 想字号 | 半天 |
| 线上提交申请 | 1 小时 |
| 工商审核下证 | 1–3 个工作日 |
| 税务报到 | 半小时（线上） |
| 申请微信支付 | 1–5 个工作日 |
| **合计** | **大约 1–2 周** |
